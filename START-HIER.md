# Start hier

Je project is voorbereid. Je hoeft nog geen eigen domein te kopen.

1. Maak een GitHub-account / repository `receptenmap`.
2. Pak dit project uit. Publiceer de **inhoud van deze map** in de repository: `package.json` hoort direct in de repository-root.
3. Maak een Firebase-project en voeg een web-app toe.
4. Activeer Google-inloggen, maak Firestore aan en publiceer `firestore.rules`.
5. Voeg je Google-e-mailadres toe als lid onder `libraries/keuken/members`.
6. Verbind de GitHub-repository met **Cloudflare Pages**.
7. Vul de Firebase-buildvariabelen in. Build: `npm run build`. Output: `dist`. Node: `22`.
8. Voeg je nieuwe `…pages.dev`-hostnaam toe aan Firebase Authentication → Geautoriseerde domeinen.
9. Test met jouw account en dat van een collega. Deel daarna de link.

De volledige uitleg en commando's staan in README.md. Het zip-bestand bevat broncode, geen reeds verbonden Firebase-project of bestaande GitHub-repository. Je eerdere recepten kun je met een JSON-export importeren.
